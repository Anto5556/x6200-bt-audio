FRONT-PANEL REMAP — RENDERS

Rendered by the radio itself, offscreen, from the shipped BtAudio.qml. On the radio the same design stage is turned 270 degrees into the panel's own 480x800 frame; the offscreen platform hands over 800x600, so it appears here unrotated.

Regenerate these with dev/render-frames.py, not by hand. Qt on this image is built without fontconfig, so it reads fonts only from the directory named by QT_QPA_FONTDIR; its compiled-in fallback, /usr/lib/fonts, does not exist here. A plain ssh root@radio '…' reads no profile and so inherits nothing, and Qt then draws every panel, border and colour with no words at all -- which reads like a broken screen rather than a broken render. The script sets the variable and refuses to render unless it can prove glyphs are being drawn, so a frame from it can be trusted for what a label says. The launcher and the boot init script both source /etc/profile, so the radio's own btaudio snapshot was never affected.
